# AI-OS をPCで起動する（デスクトップのアイコンから）

一度だけ準備すれば、あとは**アイコンをダブルクリックするだけ**で起動できます。

## 事前準備（初回だけ・1回のみ）

1. **Docker Desktop をインストール** — https://www.docker.com/products/docker-desktop/
   （AI-OS はこの上で動きます。無料です。）
2. このリポジトリをPCに用意する（`git clone` するか、ZIPで展開）。

## 起動アイコンの作り方

### Windows

1. `ai-os` フォルダを開く
2. **`START-AI-OS.bat`** を右クリック → **「送る」→「デスクトップ（ショートカットを作成）」**
3. デスクトップにできたショートカットをダブルクリックすれば起動します
   - 名前は「AI-OS 起動」などに変えてOK
   - アイコンを変えたい場合：ショートカットを右クリック →「プロパティ」→「アイコンの変更」

> ショートカットは元の `.bat` の場所（`ai-os` フォルダ）を参照して動くので、
> **`.bat` 本体は `ai-os` フォルダから動かさないでください。**

### macOS

1. `ai-os` フォルダを開く
2. **`START-AI-OS.command`** を右クリック →「エイリアスを作成」
3. できたエイリアスをデスクトップにドラッグ
   - 初回だけ「開けない」と出たら：右クリック →「開く」→「開く」で許可

## 使い方

| したいこと | ダブルクリックするもの |
|---|---|
| 起動する | **START-AI-OS**（初回は数分かかります） |
| 停止する | **STOP-AI-OS** |

起動すると自動でブラウザが開き、次のURLで使えます：

- 画面（管理UI）: http://localhost:3000
- API仕様書: http://localhost:8000/docs

## うまくいかないとき

- **「Docker が起動していません」と出る** → 先に Docker Desktop を起動してから、もう一度アイコンを実行。
- **ブラウザは開いたが真っ白/エラー** → 初回はビルド中の可能性。1〜2分待ってページを再読み込み。
- **完全に消したい** → STOP-AI-OS を実行後、Docker Desktop でイメージを削除。
